One parameterized SELECT on an approved read-only connection. Joins and derived columns are explicit SQL. No automatic mapping.

Example: [{"name":"active","type":"bool","value":true}]. Parameters bind to ? in order. Use strings for decimals and large integers. NULL is null; empty text is "". Values are stored in pipeline/run snapshots.
